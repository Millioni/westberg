# WESTBERG Fashion Store

Static HTML, CSS and JavaScript prototype for the WESTBERG fashion shop school project.

Open `index.html` directly or serve this folder with a small static server.

## Image Uploads

Upload the product images manually into an `assets` folder with these exact filenames:

- `assets/jeans-long-model.png`
- `assets/jeans-long-product.png`
- `assets/jeans-short-model.png`
- `assets/jeans-short-product.png`
- `assets/tshirt-model.jpeg`
- `assets/tshirt-front.jpeg`
- `assets/tshirt-back.jpeg`
- `assets/joggers.png`
- `assets/hoodie.png`
- `assets/tracksuit-model.png`
- `assets/cap-beige.png`
- `assets/cap-blue.png`
- `assets/cap-white.png`
